# Project Card ingest runs off the app server via a push API

Building a Project Card requires reading files from `\\192.168.99.1\PS`, but the server hosting `expense-billing-app` (`psaidemo.icn21.local`) has no network path to that host — confirmed directly with the user, not assumed. Rather than wait for network access to be provisioned, Project Card ingestion is push-based: `expense-billing-app` exposes an authenticated ingest API, and an extraction script runs on whatever machine currently has share access (initially the developer's own workstation), pushing extracted records to that API on demand. Re-index for v1 is a manual trigger rather than a schedule, since the only machine with share access isn't guaranteed to be always-on. If the app server later gains network reachability to the share, extraction can move server-side and scheduling can be added without changing the Project Card data model or the ingest API's shape.
